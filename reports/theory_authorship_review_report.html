2. Detailed Derivation Analyses

2.1 Variational Leave-One-Out (LOO) Consensus & Log-Cosh Negentropy

The joint variational objective formulated in 02_methods.qmd:29-59: $$\min_{\{f_m, g_m\}_{m=1}^M} \sum_{m=1}^M \left[ \mathcal{L}_{\text{recon}}(\mathbf{X}_m, g_m(\mathbf{Z}_m)) + \lambda_{\text{sim}} \mathcal{L}_{\text{align}}(\mathbf{Z}_m, \mathbf{U}_{\neq m}) + \gamma D(\mathbf{V}_m) \right] + \mathcal{R}(\mathbf{Z})$$ properly quarantines modality $m$ by defining $\mathbf{U}_{\neq m} = \text{Consensus}(\{\mathbf{Z}_j\}_{j \neq m})$. The log-cosh negentropy contrast functional gradient: $$\nabla_{\mathbf{V}_m} \mathcal{L}_{\text{log-cosh}} = \frac{1}{n} \mathbf{X}_m^T \mathbf{U}_{\neq m} \tanh(\mathbf{S}), \quad \mathbf{S} = \mathbf{U}_{\neq m}^T \mathbf{X}_m \mathbf{V}_m \in \mathbb{R}^{k \times k}$$ is bounded because $|\tanh(s)| < 1$ for all $s \in \mathbb{R}$.

Advisory Note (Minor Notation Erratum): In Equation (47) of paper/02_methods.qmd, the double summation is written as: \sum_{i=1}^k \sum_{j=1}^n (|S_{ji}| - \log 2 + \dots). Because $\mathbf{S} = \mathbf{U}_{\neq m}^T \mathbf{X}_m \mathbf{V}_m \in \mathbb{R}^{k \times k}$, its indices span $i, j \in \{1, \dots, k\}$. The inner sum should be indexed to $k$ rather than $n$ (the $1/n$ normalizer outside divides by the sample count). This is purely a typographical index notation slip and does not affect the gradient formula or implementation.

2.2 Sylvester Polar Retraction & Newton-Schulz Quadratic Convergence

The manuscript eliminates SVD backpropagation singularities by formulating polar factor differentials via the continuous Lyapunov system: $$\mathbf{H}(d\mathbf{H}) + (d\mathbf{H})\mathbf{H} = d(\mathbf{Y}^T \mathbf{Y}) = (d\mathbf{Y})^T \mathbf{Y} + \mathbf{Y}^T (d\mathbf{Y})$$ Because $\mathbf{H} = (\mathbf{Y}^T \mathbf{Y})^{1/2} \succ 0$, all eigenvalues are strictly positive ($\lambda_i > 0$), guaranteeing that $\lambda_i + \lambda_j > 0$ never vanishes. This cleanly resolves the clustering singularity $(\sigma_i^2 - \sigma_j^2)^{-1}$ inherent to SVD autograd.

The forward iteration $\mathbf{Y}_{\tau+1} = \frac{1}{2}\mathbf{Y}_\tau (3\mathbf{I}_k - \mathbf{Y}_\tau^T \mathbf{Y}_\tau)$ decouples into scalar singular value recurrences: $$\sigma_{\tau+1, i} = \frac{1}{2}\sigma_{\tau, i}(3 - \sigma_{\tau, i}^2)$$ Substituting $\sigma_{\tau, i} = 1 - \epsilon_{\tau, i}$ yields: $$\epsilon_{\tau+1, i} = \frac{3}{2}\epsilon_{\tau, i}^2 - \frac{1}{2}\epsilon_{\tau, i}^3 = \epsilon_{\tau, i}^2 \left(\frac{3 - \epsilon_{\tau, i}}{2}\right) = \mathcal{O}(\epsilon_{\tau, i}^2)$$ proving quadratic convergence. Pre-scaling by $\|\mathbf{Y}\|_F$ guarantees $\sigma_{0, i} \in (0, 1] \subset (0, \sqrt{3})$, ensuring monotonic contraction.

2.3 Normalized Frame Defect & Zero Radial Force Invariant

The scale-invariant normalized frame defect is: $$D(\mathbf{V}) = \frac{1}{1 - 1/k} \left\| \frac{\mathbf{V}^T \mathbf{V}}{\text{tr}(\mathbf{V}^T \mathbf{V})} - \frac{1}{k}\mathbf{I}_k \right\|_F^2 = \frac{1}{1 - 1/k}\left(\frac{1}{\text{EffRank}(\mathbf{V})} - \frac{1}{k}\right)$$ The gradient evaluates in closed form: $$\nabla_{\mathbf{V}} D(\mathbf{V}) = \frac{4}{t^2(1 - 1/k)} \left[ \mathbf{V}\mathbf{S} - \frac{\|\mathbf{S}\|_F^2}{t}\mathbf{V} \right]$$ Evaluating the matrix inner product: $$\langle \nabla_{\mathbf{V}} D(\mathbf{V}), \mathbf{V} \rangle = \frac{4}{t^2(1 - 1/k)} \left[ \text{tr}(\mathbf{S}^2) - \frac{\|\mathbf{S}\|_F^2}{t}\text{tr}(\mathbf{S}) \right] = \frac{4}{t^2(1 - 1/k)} \left[ \|\mathbf{S}\|_F^2 - \|\mathbf{S}\|_F^2 \right] \equiv 0$$ This is corroborated by Euler's homogeneous function theorem ($D(\alpha \mathbf{V}) = D(\mathbf{V}) \implies \text{degree } 0$).

2.4 Subspace vs. Basis Axis Disentanglement

The OLS projection hat matrix for $\mathbf{Z}_2 = \mathbf{Z}_1 \mathbf{M}$ ($\mathbf{M} \in \text{GL}(k, \mathbb{R})$): $$\mathbf{H}_{\mathbf{Z}_2} = (\mathbf{Z}_1 \mathbf{M}) \left( \mathbf{M}^T (\mathbf{Z}_1^T \mathbf{Z}_1) \mathbf{M} \right)^{-1} (\mathbf{Z}_1 \mathbf{M})^T = \mathbf{Z}_1 \mathbf{M} \mathbf{M}^{-1} (\mathbf{Z}_1^T \mathbf{Z}_1)^{-1} (\mathbf{M}^T)^{-1} \mathbf{M}^T \mathbf{Z}_1^T \equiv \mathbf{H}_{\mathbf{Z}_1}$$ This proves that linear probes (OLS regression) are mathematically incapable of detecting basis rotations. Consequently, downstream evaluations must deploy coordinate-sensitive tree probes (Random Forests) alongside linear probes to distinguish subspace capture from canonical axis disentanglement.
