2. Forensic Analysis of Discovered Anomalies

Finding 1: Upstream ANTsTorch Transposed Cholesky Factor in _z_from_whitened_full

Location: /Users/stnava/data/repos/ANTsTorch/antstorch/lamnr_flows/apply_lamnr_flows_whitener.py:171

Observation: When applying direction="inverse" with input_space="whitened_full", the reconstruction error is ~1.65 instead of < 10-14.

Mathematical Derivation:

In forward extraction (lines 160-161):

L = torch.linalg.cholesky(Sigma)        # Lower-triangular Cholesky factor: L @ L.T = Sigma
yT = torch.linalg.solve(L.T, zc.T)      # y.T = (L.T)^(-1) @ zc.T
# Transposing both sides:
# y = zc @ L^(-1)

To invert $y$ back to $z_c$, multiply by $L$ on the right: $z_c = y L$. However, line 171 in ANTsTorch states:

# CURRENT BUGGY CODE (line 171):
return eps_full.to(torch.float64) @ L.T + q0.loc.to(torch.float64)

# PROPOSED FIX:
return eps_full.to(torch.float64) @ L + q0.loc.to(torch.float64)

Empirical Proof: Replacing @ L.T with @ L immediately reduces the reconstruction error from 1.65407 down to 8.88178e-16 (exact machine precision).
