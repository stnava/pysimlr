C.1 Model Formulation & Deductive Stage 5 Architecture

To resolve the “Information Masking” problem inherent in deep multi-modal normalizing flows while preserving exact input-boundary auditability, Flow-SiMR-V prepends a Stiefel-constrained Only Linear Encoder Entrypoint (OLEE) matrix \(\mathbf{V}_m \in \text{St}(k, p_m)\) to each view’s volume-preserving Normalizing Flow. This architecture establishes a globally interpretable linear bottleneck at the input boundary while retaining bijective density mapping, conditional cross-view inference, and geodesic trajectory interpolation on the \(k\)-dimensional consensus space. The normalizing flows are implemented natively in PyTorch, adapting coupling structures from the Latent-Aligned Multiview Normalizing Flows (LAMNr Flows) framework (ntustison/LAMNrFlows).

C.1.1 Mathematical Formulation

For each input modality \(\mathbf{X}_m \in \mathbb{R}^{n \times p_m}\) (\(m = 1, \dots, M\)):

  1. Stage 1 — Only Linear Encoder Entrypoint (OLEE) Bottleneck: \[\mathbf{Z}_{m,\text{lin}} = \mathbf{X}_m \mathbf{V}_m, \quad \text{subject to } \mathbf{V}_m^\top \mathbf{V}_m = \mathbf{I}_k\] where \(\mathbf{V}_m \in \mathbb{R}^{p_m \times k}\) is retracted onto the Stiefel manifold via the NSA-Flow Sylvester polar factor / Newton-Schulz flow with optional disjoint non-negative support.

  2. Stage 5 — Low-Dimensional Bijective Normalizing Flow: \[\mathbf{Z}_m = f_{\text{flow}, m}(\mathbf{Z}_{m,\text{lin}})\] where \(f_{\text{flow}, m}: \mathbb{R}^k \to \mathbb{R}^k\) is a composition of RealNVP affine coupling layers with exact analytical inverse \(f_{\text{flow}, m}^{-1}\) and tractable log-determinant \(\log |\det J_{f_{\text{flow}, m}}(\mathbf{Z}_{m,\text{lin}})|\).

  3. Stage 2 — Consensus Mixing, Topology, and Inverse Reconstruction: \[\mathbf{U} = \mathcal{M}(\mathbf{Z}_1, \dots, \mathbf{Z}_M; \mathbf{w}), \quad \hat{\mathbf{X}}_m = f_{\text{flow}, m}^{-1}(\mathbf{U}) \mathbf{V}_m^\top\]

C.2 Rectangular OLEE Prior Collapse & The Detached-Prior Solution

A critical theoretical difference separates square full-dimensional normalizing flows (Flow-SiMR, where \(f_{\text{flow},m}: \mathbb{R}^{p_m} \to \mathbb{R}^{p_m}\)) from rectangular OLEE-bottlenecked flows (Flow-SiMR-V, where \(\mathbf{V}_m \in \mathbb{R}^{p_m \times k}\) with \(k \ll p_m\) precedes \(f_{\text{flow},m}: \mathbb{R}^k \to \mathbb{R}^k\)).

C.2.1 Why End-to-End Gaussian Prior Gradients Collapse \(\mathbf{V}_m\)

In standard normalizing flows, maximum likelihood training minimizes the negative log-likelihood under a standard isotropic Gaussian prior \(p(\mathbf{z}) = \mathcal{N}(\mathbf{0}, \mathbf{I}_k)\): \[ \mathcal{L}_{\text{NLL}}(\mathbf{Z}_{m,\text{lin}}; f_{\text{flow},m}) = \frac{1}{2n}\sum_{i=1}^n \|f_{\text{flow},m}(\mathbf{z}_{m,\text{lin},i})\|_2^2 - \frac{1}{n}\sum_{i=1}^n \log \left|\det \frac{\partial f_{\text{flow},m}}{\partial \mathbf{z}_{m,\text{lin}}}(\mathbf{z}_{m,\text{lin},i})\right| \] When \(f_{\text{flow},m}\) acts on the full ambient space \(\mathbb{R}^{p_m}\), the change-of-variables formula is exact because the mapping is square and invertible on \(\mathbb{R}^{p_m}\). However, when the rectangular projection \(\mathbf{Z}_{m,\text{lin}} = \mathbf{X}_m \mathbf{V}_m\) (\(k \ll p_m\)) precedes the flow, the change-of-variables determinant \(\log |\det J_{f_{\text{flow},m}}|\) accounts only for volume changes inside the \(k\)-dimensional subspace and contains no log-determinant term for the subspace selection \(\mathbf{V}_m\).

If \(\nabla_{\mathbf{V}_m} \mathcal{L}_{\text{NLL}}\) is backpropagated into \(\mathbf{V}_m\), the quadratic penalty \(\frac{1}{2}\|\mathbf{Z}_m\|_2^2 = \frac{1}{2}\operatorname{tr}(\mathbf{V}_m^\top \mathbf{X}_m^\top \mathbf{X}_m \mathbf{V}_m) + \mathcal{O}(\|f_{\text{flow},m} - \text{Id}\|)\) is minimized on the compact Stiefel manifold \(\text{St}(k, p_m)\) by rotating \(\mathbf{V}_m\) onto the trailing eigenvectors of \(\mathbf{X}_m^\top \mathbf{X}_m\) with the smallest eigenvalues \(\lambda_{p_m-k+1}, \dots, \lambda_{p_m}\). Because the coupling layers can trivially rescale small-variance inputs via their log-scale networks \(s_\ell(\cdot)\) to match unit variance in \(\mathbf{Z}_m\), the joint objective is minimized by discarding the leading biological variance directions and projecting onto low-variance noise axes.

C.2.2 Detached-Prior Subspace-Decoupled Optimization

To prevent rectangular prior collapse, Flow-SiMR-V enforces detached-prior subspace decoupling:

  1. OLEE Basis Update (\(\mathbf{V}_m\)): The Stiefel basis \(\mathbf{V}_m\) is updated exclusively by the cross-view consensus alignment energy \(\mathcal{E}_{\text{align}}\) and the within-view spectral fidelity loss \(\mathcal{L}_{\text{recon}} = \frac{1}{M}\sum_{m=1}^M \frac{\|\mathbf{X}_m - f_{\text{flow},m}^{-1}(\mathbf{Z}_m)\mathbf{V}_m^\top\|_F^2}{\|\mathbf{X}_m\|_F^2}\), while detaching \(\mathbf{Z}_{m,\text{lin}}\) at the input to the Gaussian prior penalty (\(\text{sg}(\mathbf{Z}_{m,\text{lin}}) = \mathbf{Z}_{m,\text{lin}}.\text{detach}()\)).
  2. Bijective Flow Update (\(f_{\text{flow},m}\)): The RealNVP coupling layers \(f_{\text{flow},m}\) are trained via \(\mathcal{L}_{\text{NLL}}(f_{\text{flow},m}(\text{sg}(\mathbf{Z}_{m,\text{lin}}))) + \mathcal{L}_{\text{align}} + \mathcal{L}_{\text{recon}}\), accompanied by a zero-initialized residual identity start (\(s_\ell = 0, t_\ell = 0\) at epoch 0 so \(f_{\text{flow},m}^{(0)}(\mathbf{Z}_{m,\text{lin}}) = \mathbf{Z}_{m,\text{lin}}\)).

In our 1,214-combination sweep on ADNI-MCI (\(N=1,084\), 4 views, bipartite graph topology), this single mathematical correction raises Flow-SiMR-V out-of-sample CogPC1 \(R^2\) from \(0.0369\) (collapsed trailing-eigenvalue subspace) to \(0.2966\) (\(+704\%\) improvement), matching linear and deep OLEE benchmarks while preserving exact flow invertibility.

C.4 Algorithm for Flow-SiMR-V with Detached-Prior & Delayed Gating Warmup

To stably optimize the joint-variational objective without rectangular prior collapse or early dynamic weight collapse, Flow-SiMR-V trains the linear Stiefel encoders, normalizing flows, and dynamic MAI weights using the decoupled block-coordinate procedure below:

  1. Iteration-0 Linear Stiefel Warm Start:
    • Initialize \((\mathbf{V}_1^{(0)}, \dots, \mathbf{V}_M^{(0)})\) using a fast 15-iteration linear Stiefel solver (simlr / simlr_lbfgs) and initialize all RealNVP coupling layer scale/translation weights to zero so \(f_{\text{flow},m}^{(0)}(\mathbf{Z}_{m,\text{lin}}) = \mathbf{Z}_{m,\text{lin}}\).
  2. Forward Pass:
    • Project features to the OLEE linear subspace: \(\mathbf{Z}_{m,\text{lin}} = \mathbf{X}_m \mathbf{V}_m\) for \(m=1, \dots, M\).
    • Apply normalizing flows: \(\mathbf{Z}_m = f_{\text{flow}, m}(\mathbf{Z}_{m,\text{lin}})\).
    • Compute shared consensus coordinates \(\mathbf{U}\) (or topology-specific targets \(\mathbf{T}_m\) under star, loo, or directed/bipartite graph).
  3. Delayed MAI Gating Schedule:
    • For epoch \(t < T_{\text{delayed}}\): set modality weights uniformly \(w_m = 1/M\).
    • For epoch \(t \ge T_{\text{delayed}}\): update \(w_m\) via temperature-scaled softmax over the cross-view Modality Alignment Index \(\text{MAI}_m\).
  4. Detached-Prior Loss Computation & Retraction:
    • Evaluate Gaussian prior negative log-likelihood \(\mathcal{L}_{\text{NLL}}\) on \(f_{\text{flow},m}(\text{sg}(\mathbf{Z}_{m,\text{lin}}))\) so prior gradients update only \(f_{\text{flow},m}\).
    • Evaluate alignment energy \(\mathcal{E}_{\text{align}}\) and reconstruction loss \(\mathcal{L}_{\text{recon}} = \frac{1}{M}\sum_m \|\mathbf{X}_m - f_{\text{flow},m}^{-1}(\mathbf{Z}_m)\mathbf{V}_m^\top\|_F^2 / \|\mathbf{X}_m\|_F^2\) end-to-end through both \(f_{\text{flow},m}\) and \(\mathbf{V}_m\).
    • Retract updated \(\mathbf{V}_m\) onto the Stiefel manifold via NSA-Flow Sylvester polar / Newton-Schulz retraction.
