2. Mathematical Mechanism & Proximal-Quartic Formulation

Inside each block sweep (consensus u held fixed), _smooth_objective(V) is indefinite around the incoming constrained iterate V_0 for two structural reasons:

  • 0-Homogeneous Radial-Tangential Saddle: Column normalisation w_j = v_j / ||v_j||_2 (and scale-free similarities nc and correlation_penalty) satisfy Euler's identity ∇²_{v_j v_j} E(V) v_j = -∇_{v_j} E(V), producing an exact 2×2 saddle with eigenvalues ±||∇_{v_j} E||_2 / ||v_j||_2 whenever the block gradient is non-zero.
  • Off-Stiefel Cross-Column Curvature: orthogonality_defect(V) = ||V⊤V - I||_F² contributes 4 W_orth ⟨V_0⊤V_0 - I, D⊤D⟩ on span(V_0)⊥ (measured at -32.44 when W_orth ≈ 833 and off-diagonal correlation is 0.01), while nc and correlation_penalty are non-convex in angle.
Proximal-Quartic Alternating Minimization Subproblem (NSALBFGSB.step):
Φ(V; V_0) = E(V) + (μ_2 / 2) ||V - V_0||_F² + (μ_4 / 4) ||V - V_0||_F⁴,   μ_2 = 2.5 / s_0²,   μ_4 = 64.0 / (s_0² ||V_0||_F²),   s_0² = ||V_0||_F² / k.
At V = V_0, both the regulariser value and gradient vanish identically (Φ(V_0; V_0) = E(V_0), ∇Φ(V_0; V_0) = ∇E(V_0)), leaving fixed-point stationarity, outer energy values, and package defaults unchanged. μ_2 convexifies local negative curvature and pins the radial column-norm gauge; μ_4 provides a C∞ soft trust region near relative excursion ||V - V_0||_F / ||V_0||_F ≈ 0.25 against stale-consensus overshoot.
